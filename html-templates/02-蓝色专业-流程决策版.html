AGENT CANVAS TEMPLATE

智能流程治理单元

突出关键节点、人工决策与自动化执行边界

一句话概括：通过人机协作，将分散信息转化为可追踪、可审核、可复用的标准流程，同时保留关键决策的人工把关。

1Intent（意图）

◎ 目标 Goal

围绕某类高频业务事项，建立从信息收集、分析建议到执行归档的完整闭环。

◇ 价值 Value

  • 降低重复沟通与人工整理成本
  • 提高流程一致性与结果可追溯性
  • 沉淀可复用的知识、规则与模板

↗ 成功指标

  • 处理周期缩短 ≥ 50%（示例）
  • 一次通过率 ≥ 85%（示例）
  • 内部满意度 ≥ 4.5 / 5（示例）

2User（用户）

● 主要用户

业务执行人员、项目负责人、专业审核人员与协作方代表。

◆ 核心需求

  • 快速理解事项背景与规则依据
  • 获得结构化建议与下一步行动
  • 关键节点可确认、可退回、可追踪

! 典型痛点

  • 信息分散，查找与核对耗时
  • 依赖个人经验，输出质量不稳定
  • 过程证据不足，复盘与交接困难

3Agent Team（人 + Agent）

角色主要职责自动化决策边界
业务负责人确认目标、范围与关键结果否最终审批与例外决策
智能助手检索规则、生成建议、记录过程是只建议，不替代授权
专业审核人审核依据、风险与输出内容否专业判断与放行
协作方代表补充信息、确认交付与反馈否确认自身职责范围

4Workflow（工作流）

1事项触发人工 / 系统触发
2信息汇总智能助手辅助
3规则匹配智能助手辅助
4管理者决策人工确认点
5执行同步智能助手辅助
6结果复盘形成可复用资产

5Context（上下文）

▤ 知识库

  • 制度、流程与常见问题
  • 标准操作手册与范例
  • 规则边界与例外场景

◉ 数据源

  • 内部业务系统（示例）
  • 文档与沟通记录
  • 状态、结果与历史反馈

⌘ 工具

  • 文档解析与结构化抽取
  • 流程编排与消息提醒
  • 审批、归档与报表工具

6Validation（闭环验证）

✓ 能否执行？

关键输入可获得，人工确认点与异常处理路径清晰。

↗ 能否创造价值？

从周期、成本、质量、风险和满意度进行前后对比。

∞ 能否持续进化？

持续沉淀提示词、流程、知识、最佳实践和结构化数据。

一句话总结这是一个“可理解、可协作、可审计、可迭代”的最小智能协作单元模板。
