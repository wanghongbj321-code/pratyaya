# 组件库

- 通过边框粗细而非颜色区分层级（3px → 2px → 1px）
- 卡片用浅灰底 + 1px 边框，不使用阴影
- 表格用极简线条，无斑马纹
- 工作流节点用实线圆 + 箭头
- Hero / Canvas 标题带：左侧粗竖线 (4px) + 简洁标题文字
- 质量面板：浅灰底 + 1px 边框，信息用表格对齐
- **Pan-Mode Invariants（v2.3.5+ 锚定基准）**：本模式是 pan-mode 13 条不变量 §14.5 的**唯一已默认正确实现模式**（Hero 白纸底 + 主色仅作 eyebrow / 4px 左线 / 行动摘要 5px 左线 / pale 卡背景；无阴影 / 无渐变 / 无彩色强信号）。其它 9 模式都以本模式为参照校对。

# 适用场景

正式打印、管理层报告、学术场景、黑白打印机友好。适合需要高度正式感、不希望色彩干扰信息传递的场景。

# 反例

- 不要使用彩色强调（红/绿/蓝/紫等）
- 不要使用渐变或阴影
- 不要混搭其他模式的色板 token（如蓝/橙/紫等彩色系统）
- 不要在高密度内容上使用过粗边框（超过 3px）
- 不要在黑白打印机输出时依赖颜色传达信息
- 不要使用背景色差作为唯一的层级区分手段
