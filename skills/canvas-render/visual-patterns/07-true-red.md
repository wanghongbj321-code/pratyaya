# True Red — 正红版

## 色板 token

| 用途 | Hex | CSS 变量建议 |
|---|---|---|
| 页面背景 | `#f9f9f9` | `--red-light` |
| 纸张 / Canvas | `#ffffff` | `--paper` |
| 主红 | `#cc0000` | `--true-red` |
| 深红 | `#8a0000` | `--red-dark` |
| 浅红 | `#fff0f0` | `--red-pale` |
| 主文字 | `#111111` | `--ink` |
| 辅助文字 | `#6a6a6a` | `--muted` |
| 边框 | `#e5e5e5` | `--line` |
| 深色行动信号 | `#222222` | `--accent` |
| 成功背景 / 文字 | `#edf6f0` / `#285d40` | `--success-soft` / `--success-ink` |
| 风险背景 / 文字 | `#fff0f0` / `#8a0000` | `--risk-soft` / `--risk-ink` |

红、黑、白是唯一主系统；成功状态可以使用低饱和绿，但不能发展为第二套组件语言。

## 字体

- 主字体：`"Helvetica Neue", Arial, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 页面 Hero：`clamp(28px, 3.2vw, 44px)`，字重 800，行高 1.15。
- Eyebrow：10px，字重 700，字距 `.2em`，主红。
- 行动摘要：16px，字重 500，行高 1.6；标签 11px、字重 800。
- Section 标题：14px，字重 800。
- 小标题：12px，字重 800，字距 `.05em`，可使用短标签式大写。
- 正文与列表：13px，行高 1.55。
- 表格：12px；表头字重 800。
- 指标：24px，字重 800；标签 10px。
- 工作流标题：13px，字重 800。
- 页脚结论：15px，字重 800。

## 网格

- 页面容器：`max-width: 1400px; margin: auto; padding: 36px 32px 48px`。
- Hero 底部使用 4px 主红规则线；行动摘要位于 Canvas 前。
- Canvas：`padding: 28px 32px 32px`。
- Balanced 主网格：`grid-template-columns: 1fr 1fr 1.4fr; gap: 22px; margin-bottom: 22px`。
- 底部网格：`grid-template-columns: 1fr 1fr; gap: 22px`。
- Workflow：`gap: 16px; padding: 16px`；节点 `min-width: 140px`。
- 三联内容：`repeat(3, 1fr)`。
- 1100px 及以下：主网格两列，Agent Team 跨满。
- 720px 及以下：页面 padding `20px 16px`；所有主要网格单列；flow 改为纵向并隐藏箭头。

## 组件库

- **Hero**：黑色大标题、红色 eyebrow、4px 红色底线，直接提出管理层要处理的问题或结论。
  - **Pan-Mode Invariants（v2.3.5+）**：Hero 卡片**必须白纸底**（v2.3.5 §6.1 落地），主红 `#cc0000` 仅作用于 eyebrow / 标题色 / 4px 主红底线 / 行动摘要 5px 左线 / pale 卡背景；**禁止 hero 整片铺红**（违反 §反例 第 1 条 "不把每个 section / 数字 / 按钮都涂成红色"）。
- **行动摘要**：浅红背景、5px 主红左边框；使用“行动结论 / 决策要求 / 下一步”等短标签。
- **Canvas**：白纸、1px 中性边框、宽松内边距。
- **Section**：白底、细灰边框；标题为主红实底白字；编号为白底主红圆点。
- **表格**：浅红表头、主红文字、2px 主红底线；正文保持黑色，避免整表红字。
- **工作流**：浅灰容器、白色节点、3px 主红顶边；红色箭头强调行动顺序。
- **行动指标**：少量 24px 主红数字配灰色标签；指标旁应说明行动含义或阈值状态。
- **洞察 / 行动卡**：洞察使用白底黑字，行动使用浅红底或红色左边线；两者不得仅靠位置区分。
- **质量面板**：浅红背景、主红标题；完整呈现版本、确认、缺口、风险和 alignment。
- **本地批注**：白底、灰色虚线边框、红色 focus outline。
- **页脚**：主红实底白字，按“行动标签 + 结论 / 下一步”组织。
- **打印**：页面背景改白、Canvas 去边框；隐藏导航和编辑控件，保留行动结论、版本、确认、风险、质量面板和批注内容。

## 适用场景

- 高管汇报、行动洞察、需要明确决策与下一步的简洁 Canvas。
- 信息密度中等，结论和行动优先于方法论细节。
- 需要强对比、快速扫读和少量关键指标的管理层材料。
- 适合会议讨论、打印批注和后续责任确认。

## 反例

- 不把每个 section、数字和按钮都涂成红色。
- 不用复杂渐变、3D 图形、圆润胶囊或大面积阴影削弱行动感。
- 不将中高密度流程强塞进本模式；高密度控制点应选 flow 模式。
- 不复制旧模板中的行动标题、指标、结论、角色或脚注内容。
- 不用红色替代语义标签；风险、行动和普通重点必须有文字说明。
- 不隐藏质量面板、本地批注或确认状态。
- 不加载外部字体、品牌 Logo、CDN 图标或网络脚本。
