# 协作规则

> 用途：M1 开场导入，全组共同约定。

## 五条协作规则

1. **真实优先**：锚定真实案例与数据，不讨论假设性问题
2. **车位留给业务**：业务发言不打断，术语当场翻译
3. **原型思维**：不争论"能不能"，只做"试试看"
4. **时间盒神圣**：到点即停，未完成进停车场（Parking Lot）
5. **Parking Lot**：悬而未决全部上墙留痕，不散会不消失

## 导入方式

- 导师逐条念 + 解释
- 全组举手表决通过
- 打印上墙，全程可见
- 违反时导师有权叫停并提醒

## 导师话术

- "我们今天的规则是：谁先讲完业务事实，谁再讲技术判断。"
- "时间盒到了就停，没讨论完的贴到停车场墙上，我们最后 10 分钟一起过。"
