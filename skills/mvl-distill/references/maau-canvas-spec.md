# MAAU Canvas 字段与视觉规范

MAAU（Minimum Agentic Autonomous Unit）画布是 MVL 工作坊的最终可视化交付物。本规范定义了生成模块 HTML 与全局画布时必须遵守的字段与视觉规则。

## 整体结构

```
┌────────────────────────────────────────────┐
│ 标题栏：MAAU 名称 + 一句话概括              │
├──────────┬──────────┬──────────────────────┤
│ 1 Intent │ 2 User   │ 3 Agent Team         │
├──────────┴──────────┴──────────────────────┤
│ 4 Workflow（横向流程图，占整行或大半行）      │
├──────────────────────┬─────────────────────┤
│ 5 Context            │ 6 Validation        │
├──────────────────────┴─────────────────────┤
│ 底栏：一句话总结（+ 推断说明）               │
└────────────────────────────────────────────┘
```

## 六板块字段规范

### 1. Intent（意图）
- **目标 Goal**：一段话，含业务背景与闭环范围
- **价值 Value**：分条列出，每条对应受益者
- **成功指标 Success Metrics**：分条，必须含量化数字（如「续费完成率 ≥ 99.9%」）

### 2. User（用户）
- 表格或卡片：**用户 / 需求 / 痛点 / 最重要的结果**
- 「最重要的结果」每类用户一句话，是板块视觉重心

### 3. Agent Team（人 + Agent）
- 表格：**角色 / 职责 / 是否Agent / 决策边界**
- 「是否Agent」列：是（Agent）/ 否（人）/ 部分（系统能力）
- **三明治分层**（推荐）：每个角色标注所属层——Silicon 执行（Agent：检索/比对/初稿，可错但快）· Carbon 复核（人：抽样复核/例外裁决）· Carbon 决策（人：拍板担责）；「决策边界」写清"可自决什么 + 必须升级什么"
- 底部一句**协作模式**说明：谁主导、人在哪些关键节点把关

### 4. Workflow（工作流）
- 编号步骤流程图，节点类型三选一并以色块/图例区分：
  - **自动化节点**（Agent 主导/执行）
  - **人工确认节点**（人审）
  - **人审 + Agent 执行节点**
- 流程图旁配：自动化节点清单、人工确认节点清单、关键规则（阈值/频率/SLA）
- 冻结版 Workflow 以 M4 为准

### 5. Context（上下文）
- 三栏：**知识库 / 数据源 / 工具（技能）**
- 每条注明来源；不确定的标「（推断）」

### 6. Validation（闭环验证）
- 三问三段：
  1. **能否执行**：结论 + 依据（数据可得性、流程覆盖、人机分工）
  2. **能否创造价值**：表格（价值维度 / 可衡量指标 / 如何衡量）
  3. **能否持续进化**：资产沉淀清单（Prompt / Workflow / SOP / Knowledge / Agent / Template / Best Practice / 数据资产）

### 顶部与底部
- 顶部：**MAAU 名称**（项目代号 + 一句话概括：通过什么，为谁实现什么）
- 底部：**一句话总结**（全组逐字确认版）+ 推断说明（哪些内容是合理推断、需设计阶段确认）

## 模块 → 板块映射（增长式填充）

| 模块 | 填充板块 |
|------|---------|
| M1 | Intent 全部 |
| M2 | User 全部 + Workflow 现状素材 |
| M3 | Workflow 草案 + Intent 回填（闭环目标/验收标准） |
| M4 | Agent Team + Context + Workflow 冻结 |
| M5 | Validation 之 1、2 + 信任风控 |
| M6 | Validation 之 3 + 一句话概括/总结 |

## 视觉规范（HTML 实现）

- **模块竖版 HTML**：竖向长页，宽度约 760–900px，单文件（内联 CSS），每个内容区为圆角卡片，卡片标题带板块序号徽章与图标
- **全局画布 HTML**：横向大画布（≥1600px 宽，允许横向滚动或自适应缩放），六板块网格布局
- **配色**：深蓝主色（标题栏/表头）+ 白底卡片；板块可用强调色区分；状态语义色：绿=达成/自动化，橙=人工/风险，红=问题
- **推断标注样式**：〔推断〕内容用虚线底纹或角标「i」，hover/备注说明「基于讨论的合理推断，需确认」
- **字体**：中文无衬线；数字与指标加粗；成功指标用指标卡或表格呈现
- **打印友好**：全局画布需能在 A 类纸张横向打印时保持可读（助教可能会打印上墙）

## 设计锚点

- 参考市面上成熟的 Agent Canvas / Service Blueprint 模板的版式风格
- 保持信息层级清晰，重点突出（如"一句话概括"和"一句话总结"视觉权重高）
- 确保打印友好（A4/A3横向打印时保持可读性）
