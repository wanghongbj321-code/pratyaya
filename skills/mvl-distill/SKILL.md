# mvl-distill：工作坊转写提炼技能

将杂乱的小组讨论转写（2-5 万字、口语化、多人混杂、可能跑题）提炼为干净、结构化、可直接渲染成 MAAU 画布的模块文件。

## 输入与输出

- **输入**：某一模块的讨论转写文本（粘贴或文件）+ 对应模块框架 `frameworks/mN-*.md`
- **输出**：`modules/module-N.md`（结构化成果）+ 确认版文字 + 缺口清单 + 推断项清单

## 提炼流程（五趟处理）

### 第 0 趟：存档
把原始转写原样保存到 `transcripts/module-N-raw.md`，一字不改。这是回溯依据。

### 第 1 趟：分段
按话题转换把转写切成若干片段（不按字数硬切）。每段标一句「这段在讨论什么」。跑题、闲聊、与模块目标无关的段落标记为「不提取」，但不要删除。

### 第 2 趟：逐段提取
对有效段落，提取：结论、数字、人名/角色、争议点、被否决的方案、明确的行动项。**只提取，不总结拔高**。

### 第 3 趟：框架归并
把提取出的要点归并到 `frameworks/mN-*.md` 定义的字段结构中：
- 同一字段多人表述冲突 → 全部保留并标注「【争议】」
- 字段无对应内容 → 留空，进缺口清单
- 字段内容不完整（如指标缺基线）→ 标黄并入缺口清单

### 第 4 趟：推断标注（铁律）
- 转写中明确说到的 → 直接写入
- 你基于上下文补全、推测、合理化的 → 必须以 `〔推断〕` 前缀标注
- 推断内容同时汇总到「待确认清单」，请小组确认或删除
- **严禁把推断伪装成讨论结论**，这是本技能的第一红线

### 第 5 趟：生成确认版
输出三部分给助教：
1. **结构化文字版**（module-N.md 的内容预览，人类可读）
2. **缺口清单**：哪些字段是空的/只有结论没有依据 → 转成 3-5 个补问问题
3. **推断项清单**：所有〔推断〕内容的逐条列表

助教确认或补录后，定稿 `modules/module-N.md`。

## 长文本策略

- 转写 >1.5 万字时，必须分段处理，禁止一次性通读后凭印象总结
- 每段提取结果先落盘（临时文件或状态文件），再统一归并，防止上下文丢失
- 说话人识别错误是常态：不纠结谁说的，只关注说了什么

## 质量红线

1. 不编造：转写里没有的，要么标〔推断〕要么进补问清单
2. 不拔高：小组说到什么程度就记到什么程度，不替他们「升华」
3. 不留暗坑：所有争议、冲突、悬而未决的点必须显式呈现，不能悄悄抹平
