# M6：终极打磨、方案择优、成果演示与闭环总结

> Canvas 贡献：Validation——能否持续进化；顶部一句话概括；底部一句话总结
> 内容边界：`../references/workshop-canvas-map.md`

## 本模块必须完成

1. 完成原型最终优化并确定最终方案。
2. 按闭环完整性、落地可行性、场景适配性对比方案。
3. 演示标准化 MVL 成果并记录演示结论。
4. 复盘三轮验证数据、问题整改和落地经验。
5. 梳理能力边界、适配场景和优化空间。
6. 记录已形成或计划形成的可复用资产。
7. 输出后续迭代、规模化复制、生产化建议和推进计划。
8. 确认顶部一句话概括和底部一句话总结。

## 引导问题

1. 最终方案做了哪些优化？
2. 各方案在闭环完整性、落地可行性和场景适配性上如何对比？为什么选择最终方案？
3. 成果演示证明了什么，还没有证明什么？
4. 三轮验证数据、问题整改和经验说明了什么？
5. 当前 MVL 能做什么、不能做什么，适用于哪些场景？
6. 还存在哪些优化空间？
7. 已经形成或明确计划形成哪些可复用资产？
8. 后续迭代、规模化复制和生产化分别建议推进什么？
9. 下一步计划、负责人、时间和交付物是什么？
10. 一句话概括和一句话总结如何表达？
11. 【对齐检查】业务方和技术方对最终方案的价值判断是否一致？对能力边界和后续计划的预期是否有共识？

## `canvas_fields` 必填

| 字段 | 内容 |
|---|---|
| `final_solution` | 最终方案与终极优化 |
| `solution_comparison` | 闭环完整性 / 落地可行性 / 场景适配性对比 |
| `demo_summary` | 演示内容和结论 |
| `validation_review` | 验证数据、问题整改、经验复盘 |
| `capability_boundary` | 能做 / 不能做 |
| `applicable_scenarios` | 适配场景 |
| `optimization_space` | 优化空间 |
| `evolution_assets` | Prompt / Workflow / SOP / Knowledge / Agent / Template / Best Practice / 数据资产中实际形成或明确计划形成的项目 |
| `next_step_plan` | 迭代 / 规模化复制 / 生产化建议与推进计划 |
| `headline` | MVL 名称与一句话概括 |
| `takeaway` | 一句话总结 |

## 放行检查

- [ ] 最终方案和择优理由清晰。
- [ ] 演示结论与验证证据一致。
- [ ] 能力边界、适配场景和优化空间已确认。
- [ ] 资产只记录实际形成或明确计划形成的内容。
- [ ] 后续建议和推进计划来自本次讨论。
- [ ] 页面明确当前交付是模拟环境概念验证原型，不是生产级系统。
- [ ] 顶部和底部两句话均由小组确认。
- [ ] 业务方和技术方对最终方案的价值判断已对齐，或分歧已显式记录。
