## 引导问题清单

1. 多版方案对比：最终方案为什么胜出？（闭环完整性 / 落地可行性 / 场景适配性，逐项对比）
2. 能力边界：这个闭环能做什么、**不能做什么**？（必须各说一条以上）
3. 三轮验证数据 + 红队结果，复盘：什么超预期、什么打脸了？
4. 沉淀了哪些可复用资产？（Prompt / Workflow / SOP / 知识库 / 模板 / 最佳实践 / 数据 / 评测集 / 降级策略）
5. 跨场景视角：哪些资产可以喂给其他场景？（共用知识/数据/工具，就绪度 ●◐○）
6. 后续路线图：迭代、规模化复制、生产化建设——下一步谁、在什么时间、交付什么？
7. 一句话概括（顶部）：通过什么，为谁实现什么？
8. 一句话总结（底部）：这个闭环证明了什么？（**必须全组逐字确认**）
